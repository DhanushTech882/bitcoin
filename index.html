Launch & Deployment Options

How to run the Streamlit AI terminal on your machine or deploy it to the cloud.

☁️ 1. Streamlit Community Cloud (Recommended)

  1. Go to share.streamlit.io and log in with GitHub.
  2. Click New app and select repository DhanushTech882/bitcoin.
  3. Main file path: app.py → Click Deploy!
Deploy on Streamlit Cloud (Free)

💻 2. Run Locally in PowerShell

Run directly using your virtual environment:

.\venv\Scripts\python.exe -m streamlit run app.py

Or standard activation:

streamlit run app.py

🐳 3. Container / Render Web Service

  1. Render: Create a Web Service connected to this repo (uses included render.yaml).
  2. Docker: Build and run using the included Dockerfile:
docker build -t coinsight . && docker run -p 8501:8501 coinsight
