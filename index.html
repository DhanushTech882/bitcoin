Launch & Deployment Options

How to run the Streamlit AI terminal on your machine or deploy it to the cloud.

▲ 1. Vercel Web Portal Deployment (Ready)

  1. Import or push this repository to GitHub.
  2. Connect repository to Vercel.
  3. Pre-configured with vercel.json & .vercelignore: Zero build configuration required!
Deploy to Vercel (Instant)

☁️ 2. Streamlit Community Cloud (Python Terminal)

  1. Go to share.streamlit.io and log in with GitHub.
  2. Click New app and select repository DhanushTech882/bitcoin.
  3. Main file path: app.py → Click Deploy!
Deploy on Streamlit Cloud (Free)

💻 3. Run Locally in PowerShell

Run directly using your virtual environment:

.\venv\Scripts\python.exe -m streamlit run app.py

Or standard activation:

streamlit run app.py
